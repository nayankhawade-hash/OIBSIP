# Travel Explore - Landing Page

## Oasis Infobyte Internship

This project is created as part of the Oasis Infobyte Web Development and Designing Internship.

## Project Title

Travel Explore - Landing Page

## Objective

The objective of this project is to create a responsive and attractive landing page using HTML5 and CSS3.

## Technologies Used

- HTML5
- CSS3

## Features

- Responsive navigation bar
- Hero section
- Popular destinations section
- Services section
- About Us section
- Contact Us section
- Footer
- Responsive design for mobile, tablet and desktop
- Hover effects
- Smooth scrolling navigation

## Destinations

- Paris
- Dubai
- Switzerland

## Services

- Flight Booking
- Hotel Booking
- Travel Packages

## Responsive Design

The website has been tested on desktop and mobile screen sizes, including iPhone 12 Pro.
